# Ski Trip 2027 — Jay Peak vs. Lake Placid

A one-page static site comparing the two options for Feb 19–22, 2027.

## Publish on GitHub Pages

1. Create a new public repo (e.g. `ski-trip-2027`).
2. Add `index.html`, the `images/` folder, and this README to the root and push to `main`.
3. In the repo: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, pick `main` and `/ (root)`, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/ski-trip-2027/`.

## Things to fill in

Search `index.html` for `EDIT:` comments. Anything shown with a dashed, striped
background (`class="tbd"`) is a placeholder:

- Group size (hero chip)
- Estimated cost per person (table)
- Vote deadline and the poll link (the "Vote here" button `href`)

When a value is known, replace the whole `<span class="tbd">…</span>` with plain text.
